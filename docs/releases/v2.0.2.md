# WireView 2.0.2 — 浅色设备图标与更新提示

WireView 通过 USB 将 Android 手机或平板用作 Windows 的复制屏幕或独立扩展桌面。

## 本版更新

- 设备卡片中的手机、平板小图标适配浅色模式：浅蓝屏面、浅色边框与柔和阴影。
- 包含此前2.0.1准备版的更新功能。相较上一公开版2.0.0，控制中心与安卓接收端会在启动和运行中每6小时检查新版本。
- 控制中心的「检查更新」在「关于 WireView」标题右侧，平时不额外占空间；有新版时弹出 GitHub 和网盘下载选择，点击网盘自动复制密码 `df73`。
- 安卓仅在发现新版时显示「下载新版」，无需更新时保持原界面；使用关闭调试的 Release 包，沿用旧签名，支持保留数据覆盖升级。
- 电脑端与安卓版本统一为2.0.2，保留多设备管理、复制、扩展、托盘操作和合盖功能。

## 下载与升级

- Windows：`WireView-2.0.2-Windows-x64.zip`，完整解压后打开 `WireView 控制中心.exe`。
- Android：`WireView-2.0.2-release.apk`，可保留旧应用覆盖安装。
- 校验文件：`WireView-2.0.2-SHA256SUMS.txt`。
- [GitHub 下载](https://github.com/liujiaxing060903/WireView/releases/latest)。
- [网盘下载](https://wwbkc.lanzoue.com/b01euxnp0d)，密码：`df73`。网盘文件由发布者同步，版本判断以 GitHub 最新正式版为准。

2.0.0及更早版本需要先手动升级一次，之后即可收到更新提示。Windows需WebView2和完整Platform Tools；扩展及合盖复制另需Parsec VDD。Android最低6.0，详细步骤见[使用指南](https://github.com/liujiaxing060903/WireView/blob/main/docs/RELEASE_WINDOWS.md)。
