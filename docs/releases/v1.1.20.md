# WireView 1.1.20

发布日期：2026-10-22

本版修正控制中心在简易模式启动扩展屏幕时的目标选择，并改进失效显示器的启动处理。

## 本版改动

- 简易模式点击“扩展屏幕”时，使用当前 WireView 控制中心持有的副屏，不再沿用完整模式中选中的电脑主屏。
- 启动前重新检查目标显示器是否仍附加到 Windows。完整模式遇到失效的 `DISPLAYn` 时刷新列表并提示重新选择，避免将旧目标交给 Host 后反复报错。
- WireView 自己持有的副屏脱附时，简易扩展入口通过对应 broker 移除并重建该副屏；保留其他程序创建的显示器。
- Windows 包加入原生回退入口 `wireview_control_legacy.exe`，更新首次使用说明、第三方声明与依赖获取说明。
- Windows 和 Android 均显示版本 1.1.20；Android `versionCode` 为 20。

## 下载与使用

- [Windows x64 便携包](https://github.com/liujiaxing060903/WireView/releases/download/v1.1.20/WireView-1.1.20-Windows-x64.zip)：完整解压后运行 `WireView 控制中心.exe`。
- [Android APK](https://github.com/liujiaxing060903/WireView/releases/download/v1.1.20/WireView-1.1.20-debug.apk)：支持 Android 11 及以上，为可侧载的 Debug 签名包，与 1.1.19 使用相同签名证书。
- [SHA-256 校验文件](https://github.com/liujiaxing060903/WireView/releases/download/v1.1.20/WireView-1.1.20-SHA256SUMS.txt)。

Windows 端需 WebView2 Evergreen Runtime，并自行准备官方完整的 Android SDK Platform Tools，将 `platform-tools` 文件夹放到程序根目录。Android 需开启 USB 调试并授权电脑。扩展屏幕还需单独安装 Parsec VDD，复制主屏无需该驱动。本包不附带 ADB、ParsecVDisplay 或 Parsec VDD 安装器。

使用步骤和依赖链接见 Windows 包内的 `README.md`、`安装依赖/`，或[仓库使用说明](https://github.com/liujiaxing060903/WireView/blob/v1.1.20/docs/RELEASE_WINDOWS.md)。

## 验证与已知限制

- Windows Release 构建和 13 项 CTest 全部通过。
- Android APK 构建，以及协议、传输、持久日志三组 Java 自测全部通过；已检查 APK 版本与签名。
- 本轮未追加真实设备的扩展屏幕操作回归，构建与自测结果不代表所有设备兼容性均已验证。
- 60 FPS 为已验证的可靠档；120 FPS 仍是实验性主机编码/发送目标，不保证 Android 面板实际以 120 Hz 显示。
- Intel QSV 编码器重新协商和 HDR/10-bit 捕获的已知兼容性问题仍在；建议先使用 SDR、60 FPS，必要时降低分辨率。
- Windows 程序未配置正式代码签名；Android 包为 Debug 签名侧载包。
