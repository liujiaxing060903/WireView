# WireView 2.0.1 — 两端更新提示与 Android Release 包

WireView 通过 USB 将 Android 手机或平板用作 Windows 的复制屏幕或独立扩展桌面。本版在 2.0.0 的统一控制中心、多设备和合盖功能基础上，补齐更新入口与安卓 Release 构建。

## 检查更新

- 控制中心和安卓接收端启动时自动检查最新正式版本，运行中每6小时再检查一次。
- 控制中心将「检查更新」收在「关于 WireView」标题右侧，有新版时弹出下载选项；安卓打开后自动检查，仅发现新版时显示「下载新版」，无需更新时保持原界面。
- 有新版时提示下载；可选择 GitHub 或网盘，网盘旁显示密码 `df73`。控制中心点击网盘时自动复制密码，再打开链接。
- 检查失败可以稍后重试，投屏继续运行。下载与安装由用户操作。
- 2.0.0及更早版本需要先手动更新到2.0.1，之后才能使用更新提示。

## Android Release 构建

本版使用关闭调试的 Release APK，沿用旧版签名证书，可以保留数据覆盖安装。两端版本为2.0.1，Android最低6.0，支持复制、扩展、触控与手写笔及投屏前旋转。
