# WireView 2.0.0 — 新控制中心与多设备有线副屏

让闲置的 Android 手机和平板，成为 Windows 的第二块屏幕。

WireView 通过 USB 数据线传输电脑画面，支持复制已有屏幕和建立独立扩展桌面，也能在支持的设备上回传触控与手写笔操作。适合一边工作一边查文档、把聊天和参考资料放到副屏，或近距离演示电脑内容；不依赖 Wi-Fi，也不要求设备支持 USB-C DP 视频输出。

**本次更新相对于上一公开版 [1.1.20](https://github.com/liujiaxing060903/WireView/releases/tag/v1.1.20)。** Windows 控制中心、设置页、程序文件属性和 Android 接收端统一为 2.0.0。

## 新控制中心，更直接的操作

- 设备集中显示在左侧，按设备保存参数和状态。
- 上方「复制屏幕」「扩展屏幕」直接开始，下方分别调整复制来源和扩展参数。不改参数就使用该设备保存的设置。
- 标准分辨率、常用尺寸和自定义尺寸集中管理，可自定义宽、高与刷新率。
- 投屏时设置区切换为屏幕排布，提供方向说明、「标识屏幕」和 Windows 位置调整入口；停止后恢复设置。
- 标识改为屏幕左下角的大方框编号，短暂显示后自动消失。
- 更新浅色／深色图标与交互反馈，高级设置使用圆角箭头展开和收起。

## 多台设备，分别启动和停止

- 支持多设备独立会话，最多建立两块独立扩展屏。
- 可以使用不同来源复制，或组合复制与扩展；当前同一复制来源同时只允许一台设备使用。
- 右键托盘，悬停已连接设备即可复制、扩展或「停止此设备」，无需先打开控制中心。
- 托盘命令绑定所点设备，不再依赖控制中心当前选择。投屏中先停止这台设备，再切换模式。

## 鼠标、连接和接收端改进

- 修复部分手机和平板扩展时鼠标偏小的问题，按目标屏幕取得并绘制指针。
- 鼠标大小支持 50%～300% 输入，按设备记住，停止后调整、下次启动生效。
- 修复控制中心隐藏后重新显示白屏、停止后重开、旧连接清理及 USB 拔插恢复中的多项问题。
- 调整连接、识别、待投屏、断开和恢复提示，减少旧错误或等待文案残留。
- 修复 Android 旋转后丢失「电脑已识别」提示的问题。
- 投屏中隐藏 Android 旋转按钮；停止后恢复，便于开始前调整方向。
- 支持 Android 6.0 及以上；vivo Y66（Android 6.0.1）和小米 8（Android 10）均已用 2.0.0 真机验证复制和扩展，小米 8 另有托盘操作验证。
- 调整高刷新率设备的画面呈现节奏，保留 60 FPS 和 120 FPS 实验选项。

## 下载哪两个文件

- **Windows x64**：`WireView-2.0.0-Windows-x64.zip`，完整解压后运行 `WireView 控制中心.exe`。
- **Android 接收端**：`WireView-2.0.0-debug.apk`，安装并保持在前台。
- **校验文件**：`WireView-2.0.0-SHA256SUMS.txt`。

Android 沿用 1.1.20 的侧载签名，可保留数据覆盖安装；电脑端使用完整的新文件夹，原设备设置保存在用户目录。建议两端一起更新。

## 第一次使用

1. Android 安装并打开接收端，开启 USB 调试并授权电脑。
2. Windows 安装 WebView2 Evergreen Runtime，把官方完整 `platform-tools` 文件夹放到程序根目录。
3. 连接 USB 数据线，选中设备，按需要调整下方参数。
4. 点击上方复制或扩展，也可直接使用托盘入口。

扩展屏幕还需另行安装 Parsec VDD；普通复制无需这个驱动。发布包内「安装依赖」提供获取说明，不捆绑 Platform Tools 或第三方驱动安装器。

## 使用范围

- Windows 10／11 x64；Android 6.0 及以上。2.0.0 已在 vivo Y66（Android 6.0.1）和小米 8（Android 10）上完成真机复制和扩展验证。
- 120 FPS 仍是实验性编码与发送目标，不承诺所有设备最终稳定显示 120 帧。
- 暂不支持音频、Wi-Fi／远程连接、Windows 登录前显示和 HDR／10-bit 桌面。
- Windows 尚无正式代码签名，Android 为沿用原证书的调试签名侧载包。
